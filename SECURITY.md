# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues, pull requests or discussions.

Report them privately instead, through a GitHub security advisory for this repository (Security → Report a vulnerability, when it's enabled) or by contacting the repository owner directly on GitHub. Include what you found, how to reproduce it, and the version affected.

You'll get an acknowledgement, and the fix will be prepared privately before details are published.

## Supported versions

Only the latest release receives security fixes.
